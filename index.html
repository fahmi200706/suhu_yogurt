Kenapa ada nilai optimal
  • Yogurt di fermentasi oleh bakteri asam laktat, yaitu Streptococcus thermophilus dan Lactobacillus delbrueckii subsp. bulgaricus.
  • Suhu optimal 42,0–45,0 °C. Di bawah 42 °C bakteri starter bisa inaktif karena kedinginan. Di atas 45 °C enzim termal aktif dan yogurt bisa mulai mencair.
  • Kelembapan optimal 70–80 %RH. Terlalu kering membuat permukaan produk mengering; terlalu lembap memicu titik air yang mempercepat kerusakan.
  • Heater menyala otomatis kalau suhu di bawah 42 °C atau kelembapan keluar 70–80 %RH. Kooler/kipas menyala otomatis kalau suhu di atas 45 °C.
  • Status kelembapan memakai logika if-else tiga kondisi: di bawah 70 %RH humidifier menyala, di atas 80 %RH dehumidifier menyala, di antara 70–80 %RH semua mesin udara standby. Perintah dikirim lewat Blynk IoT Platform.
  • Semua angka bisa diubah di file config.js bagian acuan.
Cara pasang DHT22
  • DHT22 punya 3 kaki: VCC (merah, 3,3–5 V), DATA (hijau/kuning), GND (hitam).
  • Pasang resistor 10 kΩ antara DATA dan VCC. Tanpa resistor ini sensor tidak terbaca.
  • Jauhkan board dari kabel panjang, karena DHT22 sensitif terhadap panas dan memanaskan chipnya sendiri.
  • Jangan dibaca lebih cepat dari 1× per detik. Jeda 2 detik di kode ini sudah aman.
Menyambungkan ke Firebase
  • Semua pengaturan ada di file config.js, terpisah dari halaman ini.
  • Buka Realtime Database di Firebase console, salin Database URL-nya.
  • Paste URL itu ke bagian firebase.url di file config.js.
  • Uji dari browser: buka https://monitoring-plain-yogurt-default-rtdb.firebaseio.com/data.json. Kalau muncul angka, berarti sudah ada isinya.
Aturan keamanan (Rules) { "rules": { ".read": true, ".write": true } }

Aturan di atas cocok untuk demo, tapi berarti siapa pun bisa menulis angka palsu. Setelah demo selesai, minta temanmu batasi bagian .write dengan token supaya hanya ESP32 tim yang boleh mengirim data.

Kode ESP32 mengirim ke Firebase

Install library ArduinoJson lewat Library Manager, lalu upload kode ini.

#include <WiFi.h> #include <HTTPClient.h> #include <ArduinoJson.h> #include <DHT.h> const char* WIFI_SSID = "nama-wifi"; const char* WIFI_PASS = "password"; const char* URL_FB = "https://monitoring-plain-yogurt-default-rtdb.firebaseio.com/data.json"; #define PIN_DHT 4 DHT dht(PIN_DHT, DHT22); void setup() { Serial.begin(115200); dht.begin(); WiFi.begin(WIFI_SSID, WIFI_PASS); Serial.print("Menghubungkan wifi"); while (WiFi.status() != WL_CONNECTED) { delay(500); Serial.print("."); } Serial.println(" tersambung"); } void loop() { float suhu = dht.readTemperature(); float lembap = dht.readHumidity(); if (isnan(suhu) || isnan(lembap)) { Serial.println("Gagal membaca DHT22"); } else { StaticJsonDocument<120> doc; doc["suhu"] = suhu; doc["kelembapan"] = lembap; String muatan; serializeJson(doc, muatan); HTTPClient http; http.begin(URL_FB); http.addHeader("Content-Type", "application/json"); int kode = http.POST(muatan); if (kode > 0) { Serial.print("Terkirim: "); Serial.println(muatan); } else { Serial.print("Gagal kirim, error: "); Serial.println(http.errorToString(kode)); } http.end(); } delay(5000); // kirim setiap 5 detik }

Kalau Firebase belum terhubung, halaman ini otomatis memakai data contoh.
